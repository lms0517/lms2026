경쟁사 · 미수금 명단 만들기

주소를 좌표로 바꾸고(카카오), 비밀번호로 잠근 nearby-extra.js 를 만듭니다.
이 화면은 반드시 lms0517.github.io 주소로 열어야 합니다.
카카오 지도 키가 이 주소에만 열려 있어서, 파일을 내려받아 그냥 열면 좌표를 못 찾습니다.
비밀번호는 저장되지도 전송되지도 않습니다.

① 경쟁사 — 시트 붙여넣기

받으신 경쟁사-업체목록.tsv 를 열어 표 전체(머리글 포함)를 복사해 붙여 넣으세요. 엑셀에서 그대로 긁어 붙여도 됩니다. 첫 줄은 머리글이어야 합니다. name · addr · biz · cat2 · sales · fields · branch · person · lastVisit · visits 이미 lat · lng 칸이 있으면 그 값을 쓰고 좌표 찾기를 건너뜁니다.

② 미수금업체 — 시트 붙여넣기

경쟁사와 같은 방식입니다. 머리글을 포함해 붙여 넣으세요. name · code · addr · tel · amount · grade · branch · person 입고미회수 목록에 같은 업체가 있으면 그 업체가 미수금으로 바뀌고, 없으면 새로 들어갑니다.

③ 좌표 찾기

주소를 카카오로 조회합니다. 775곳이면 2분 안팎 걸립니다. 주소로 못 찾으면 업체명으로 한 번 더 찾고, 그래도 없으면 좌표 없이 남깁니다(지도에는 안 뜨고 목록에는 나옵니다).

④ 잠그기

주변 업체 앱을 열 때 넣는 데이터 비밀번호와 같아야 합니다.

⑤ 결과

내려받아 클로드에게 주시면 저장소에 nearby-extra.js 로 올립니다.
