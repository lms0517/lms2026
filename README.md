## 대시보드 안에서 앱을 늘리려면

`대시보드.html` 의 `TOOLS` 배열에 한 줄만 넣으면 카테고리 카드와 상세 목록이 따라옵니다.

```js
{id:'l6', cat:'scm', type:'app', url:'…', ic:'📦', name:'…', desc:'…'}
```

- `type:'app'` + `url` — 새 창으로 엽니다
- `type:'app'` + `view` — 대시보드 안 화면으로 엽니다 (PPS 견적앱이 이 방식)
- `type:'calc'` + `el` — 정적 계산기 노드를 상세 화면으로 옮겨 붙입니다

## 잠겨 있는 것

업무일지는 암호화되어 있습니다. 비밀번호를 한 번 넣으면 그 기기에만 저장되고, 저장소에는 암호문만 있습니다.

- 방식 — PBKDF2-SHA256 150,000회 → AES-256-GCM
- 저장 위치 — `ENC_LOG` 상수

견적앱 원가표도 같은 비밀번호로 잠글 예정입니다.

## 카카오 지도

주변 업체 화면이 카카오 지도를 씁니다. JS 키는 **도메인으로 보호**되며 `lms0517.github.io` 가 등록되어 있습니다.
등록되지 않은 도메인에서는 지도가 개략도로 대체됩니다.
