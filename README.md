# 영업마스터 (재설계)

당사 영업 담당자용 모바일 웹앱. 단일 파일(`index.html`), GitHub Pages 배포용.

## 구조

하단 탭 3개 — **사업 · 업체 · 지식**

- **사업**: 사업분야 6개 (S1 → S2 → 산업자재유통 → 글로벌비즈 → 운영장비 → 자동화솔루션)
  - 각 사업 상세는 카테고리 4개만:
    1. **사업소개서** — 소개자료 송부(카톡/문자용 메시지 복사·공유) / QR 소개서(즉석 QR + A4 인쇄용)
    2. **핵심 영업스킬** — 한 줄 피치 · 영업 포인트 · 반론(클레임) 대응
    3. **체크리스트** — 견적 전 필수 확인, 체크 후 견적요청 양식 복사
    4. **견적산출** — 사업별 계산기 (S1 렌탈료·자가 대비 / S2 운송·보관 개산 / 산업자재 필름·골판지·아이스팩 / S3 편도 비교 / 장비 임대 / S4 설비 개산) + 전문앱 연동(유니트 렌탈·운송견적·S3·엔지니어링)

## 전문 견적앱: 유니트 렌탈 (`pps/`)

S1 유니트 렌탈 전용 견적 위저드 (`pps/index.html`, 단일 파일).

- 4단계 확인: [1]사용형태(구내용/수송용·유형·업종) → [2]물동(출고량·회전일·시즌성·전산재고) → [3]거래구조(계약처/실수요처/청구처·견적종류·여신) → [4]단가·수익
- 매출 계산: 보관료(전산재고 × 원/매/일 × 매일 청구) + 수송비(출고 매당, 구내용 0) + 운반비(납품 매당)
- 결과: 표준 형식 텍스트 복사 — `업체명 : 지역, 업종, 견적종류, 물동량 n매/년, 예상매출 0.n억/년 (단가조건)`
- 상담 도구: 고객 적합도 평가(7항목 100점) / 자가 보유 대비 1회전당 비용 비교 / 반론 대응 카드 8건
- 단가 기본값은 참고용 — 수정 시 localStorage(`pps1.` 접두어) 저장. 실단가는 최신 단가표 확인.
- **업체**: 내 주변 영업대상업체 — 내부데이터(등록 업체, 거리순 정렬) + 주변검색(네이버 지도 키워드) 병행
- **지식**: 회사소개·영업 기본·교육자료 (검색/분류/직접 추가)

## 데이터

- 영업스킬·체크리스트·단가 참고 원문은 기존 `lms0517/X2026` `대시보드.html`에서 이관 (S2/산업자재/운영장비/S4). S1·글로벌은 신규 작성.
- 견적 단가 기본값은 참고용 — 화면에서 수정하면 기기(localStorage)에 저장됨.
- 업체·지식·체크 상태 모두 localStorage 저장 (서버 없음).
