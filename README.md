# 영업마스터 (재설계)

당사 영업 담당자용 모바일 웹앱. 단일 파일(`index.html`), GitHub Pages 배포용.

## 구조

하단 탭 3개 — **사업 · 업체 · 지식**

- **사업**: 사업분야 6개 (S1 → S2 → 산업자재유통 → 글로벌비즈 → 운영장비 → 자동화솔루션)
  - 각 사업 상세는 카테고리 4개만:
    1. **사업소개서** — 소개자료 송부(카톡/문자용 메시지 복사·공유) / QR 소개서(즉석 QR + A4 인쇄용)
    2. **핵심 영업스킬** — 한 줄 피치 · 영업 포인트 · 반론(클레임) 대응
    3. **체크리스트** — 견적 전 필수 확인, 체크 후 견적요청 양식 복사
    4. **견적산출** — 사업별 계산기 (S1 렌탈료·자가 대비 / S2 운송·보관 개산 / 산업자재 필름·골판지·아이스팩 / S3 편도 비교 / 장비 임대 / S4 설비 개산) + 전문앱 연동(운송견적·S3·엔지니어링)
- **업체**: 내 주변 영업대상업체 — 내부데이터(등록 업체, 거리순 정렬) + 주변검색(네이버 지도 키워드) 병행
- **지식**: 회사소개·영업 기본·교육자료 (검색/분류/직접 추가)

## 데이터

- 영업스킬·체크리스트·단가 참고 원문은 기존 `lms0517/X2026` `대시보드.html`에서 이관 (S2/산업자재/운영장비/S4). S1·글로벌은 신규 작성.
- 견적 단가 기본값은 참고용 — 화면에서 수정하면 기기(localStorage)에 저장됨.
- 업체·지식·체크 상태 모두 localStorage 저장 (서버 없음).

## 장비 견적앱 (`equip.html`) — 설치형 PWA

현대자동차 차량 견적 페이지 UI를 오마주한 그룹사 S5 장비 임대 견적앱.
홈 화면에 설치되고 오프라인(창고·현장)에서도 동작합니다.

### 화면 (하단 탭 3개)

- **견적** — 01 기종 선택(7종) → 02 내 장비 만들기(동력·외장 → 마스트·타이어 → 옵션·안전 → 운영 조건)
  - 선택 사양(기종·색상·마스트 단수·인상높이·타이어·배터리)에 따라 실시간으로 다시 그려지는 장비 SVG
  - "Best 다른 고객들이 가장 많이 선택한 사양" 도넛 통계(전체/운영센터/제조/식품·저온)
  - 하단 고정 액션바에 월 임대료 실시간 표시
- **견적함** — 업체명·메모와 함께 기기(localStorage)에 저장, 불러오기 / 공유(navigator.share) / 삭제
- **필수확인** — 「견적 필수 확인」 15항목을 현재 견적 기준으로 자동 점검, 진행률과 미확인 건수 표시.
  현장 확인이 필요한 항목(천장·도어 높이, 어태치먼트, 운전자, 번호판 주체 등)은 토글로 직접 체크

### 견적 로직 (당사 운영장비 「견적 필수 확인」 15항목 기반)

- 통로폭 입력 → 기종 적합성 판정 (1.9m 미만 VNA·오더피커 / 2.7m 미만 리치트럭 / 그 이상 카운터밸런스)
- 톤수·교대 → 충전기 단상/삼상 자동 추천 (2.5t 이상 또는 2~3교대 = 삼상)
- 납산 + 2~3교대 선택 시 리튬(기회충전) 비교 권장 경고
- 건설기계등록 자동 판정 — ①전동식 ②솔리드타이어 ③도로 외 운행 3요건 동시 충족 시에만 제외
- 동력에 따라 점검 항목 수가 달라짐 (전동 리튬 15 / 전동 납산 14 / 엔진식 12)
- **요약 시트**: 15항목 상태 + 임대료 내역 + 견적요청 양식 공유·복사
- 단가는 전부 참고용 — 최종 임대료는 현장 실사 후 확정

### PWA 구성 파일

`equip.webmanifest`(매니페스트·바로가기 3개) · `equip-sw.js`(앱 셸 캐시) ·
`icon-192.png` / `icon-512.png` / `icon-maskable-512.png` (`equip-icon.svg`에서 생성)
