# KPP 영업마스터 (재설계)

한국파렛트풀(KPP) 영업 담당자용 모바일 웹앱. 단일 파일(`index.html`), GitHub Pages 배포용.

## 구조

하단 탭 3개 — **사업 · 업체 · 지식**

- **사업**: 사업분야 6개 (PPS → SCM → 산업자재유통 → 글로벌비즈 → 물류장비 → 자동화솔루션)
  - 각 사업 상세는 카테고리 4개만:
    1. **사업소개서** — 소개자료 송부(카톡/문자용 메시지 복사·공유) / QR 소개서(즉석 QR + A4 인쇄용)
    2. **핵심 영업스킬** — 한 줄 피치 · 영업 포인트 · 반론(클레임) 대응
    3. **체크리스트** — 견적 전 필수 확인, 체크 후 견적요청 양식 복사
    4. **견적산출** — 사업별 계산기 (PPS 렌탈료·자가 대비 / SCM 운송·보관 개산 / 산업자재 필름·골판지·아이스팩 / RRPP 편도 비교 / 지게차 임대 / CES 설비 개산) + 전문앱 연동(운송견적·RRPP·엔지니어링)
- **업체**: 내 주변 영업대상업체 — 내부데이터(등록 업체, 거리순 정렬) + 주변검색(네이버 지도 키워드) 병행
- **지식**: 회사소개·영업 기본·교육자료 (검색/분류/직접 추가)

## 데이터

- 영업스킬·체크리스트·단가 참고 원문은 기존 `lms0517/X2026` `대시보드.html`에서 이관 (SCM/산업자재/물류장비/CES). PPS·글로벌은 신규 작성.
- 견적 단가 기본값은 참고용 — 화면에서 수정하면 기기(localStorage)에 저장됨.
- 업체·지식·체크 상태 모두 localStorage 저장 (서버 없음).

## 지게차 견적앱 (`forklift.html`) — 설치형 PWA

현대자동차 차량 견적 페이지 UI를 오마주한 로지스올 MHE 지게차 임대 견적앱.
홈 화면에 설치되고 오프라인(창고·현장)에서도 동작합니다.

### 화면 (하단 탭 3개)

- **견적** — 01 기종 선택(7종) → 02 내 장비 만들기(동력·외장 → 마스트·타이어 → 옵션·안전 → 운영 조건)
  - 선택 사양(기종·색상·마스트 단수·인상높이·타이어·배터리)에 따라 실시간으로 다시 그려지는 지게차 SVG
  - "Best 다른 고객들이 가장 많이 선택한 사양" 도넛 통계(전체/물류센터/제조/식품·저온)
  - 하단 고정 액션바에 월 임대료 실시간 표시
- **견적함** — 업체명·메모와 함께 기기(localStorage)에 저장, 불러오기 / 공유(navigator.share) / 삭제
- **필수확인** — 「견적 필수 확인」 15항목을 현재 견적 기준으로 자동 점검, 진행률과 미확인 건수 표시.
  현장 확인이 필요한 항목(천장·도어 높이, 어태치먼트, 운전자, 번호판 주체 등)은 토글로 직접 체크

### 견적 로직 (KPP 물류장비 「견적 필수 확인」 15항목 기반)

- 통로폭 입력 → 기종 적합성 판정 (1.9m 미만 VNA·오더피커 / 2.7m 미만 리치트럭 / 그 이상 카운터밸런스)
- 톤수·교대 → 충전기 단상/삼상 자동 추천 (2.5t 이상 또는 2~3교대 = 삼상)
- 납산 + 2~3교대 선택 시 리튬(기회충전) 비교 권장 경고
- 건설기계등록 자동 판정 — ①전동식 ②솔리드타이어 ③도로 외 운행 3요건 동시 충족 시에만 제외
- 동력에 따라 점검 항목 수가 달라짐 (전동 리튬 15 / 전동 납산 14 / 엔진식 12)
- **요약 시트**: 15항목 상태 + 임대료 내역 + 견적요청 양식 공유·복사
- 단가는 전부 참고용 — 최종 임대료는 현장 실사 후 확정

### 장비 이미지 — 360° 회전 · 사진 · 일러스트

`photos/` 폴더에 파일을 넣으면 일러스트 대신 실물이 뜹니다. 있는 것부터 채우면 되고, 없으면 자동으로 일러스트로 대체됩니다.

| 우선순위 | 넣는 위치 | 화면 |
|---|---|---|
| ① | `photos/<기종>-360/01.jpg, 02.jpg, 03.jpg …` | 좌우로 드래그·스와이프해 돌려보는 **360° 뷰어** |
| ② | `photos/<기종>.jpg` | 단일 사진 |
| ③ | (없음) | SVG 일러스트 |

- `<기종>` = `diesel` `lpg` `elec` `reach` `picker` `stacker` `ppt`
- 엔진식에서 "전동(리튬) 전환"을 고르면 `<기종>-electric` 을 먼저 찾습니다.
- 확장자는 `jpg` → `png` → `webp` 순으로 찾습니다.

**360° 촬영 요령** — 장비를 중심에 두고 한 바퀴 돌며 **같은 높이·같은 거리**에서 촬영합니다.
24장(15° 간격) 권장, 최소 12장 · 최대 48장. 파일명은 `01`부터 두 자리 연번이며 중간이 비면 거기서 끊깁니다.
회전 영상을 찍었다면 프레임을 추출해 같은 규칙으로 넣으면 됩니다.

뷰어는 드래그·스와이프·좌우 화살표키로 조작하고, 처음 한 바퀴는 자동으로 돌아 회전이 된다는 것을 알려줍니다
(기기가 "동작 줄이기" 설정이면 자동 회전은 생략). 받은 사진은 서비스워커가 캐시해 현장에서 오프라인일 때도 뜹니다.
