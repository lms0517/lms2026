# KPP 영업마스터 (재설계)

한국파렛트풀(KPP) 영업 담당자용 모바일 웹앱. 단일 파일(`index.html`), GitHub Pages 배포용.

## 구조

하단 탭 3개 — **사업 · 업체 · 지식**

- **사업**: 사업분야 6개 (PPS → SCM → 산업자재유통 → 글로벌비즈 → 물류장비 → 자동화솔루션)
  - 각 사업 상세는 카테고리 4개만:
    1. **사업소개서** — 소개자료 송부(카톡/문자용 메시지 복사·공유) / QR 소개서(즉석 QR + A4 인쇄용)
    2. **핵심 영업스킬** — 한 줄 피치 · 영업 포인트 · 반론(클레임) 대응
    3. **체크리스트** — 견적 전 필수 확인, 체크 후 견적요청 양식 복사
    4. **견적산출** — 사업별 계산기 (PPS 렌탈료·자가 대비 / SCM 운송·보관 개산 / 산업자재 필름·골판지·아이스팩 / RRPP 편도 비교 / 지게차 임대 / CES 설비 개산) + 전문앱 연동(운송견적·RRPP·엔지니어링)
- **업체**: 내 주변 영업대상업체 — 내부데이터(등록 업체, 거리순 정렬) + 주변검색(네이버 지도 키워드) 병행
- **지식**: 회사소개·영업 기본·교육자료 (검색/분류/직접 추가)

## 데이터

- 영업스킬·체크리스트·단가 참고 원문은 기존 `lms0517/X2026` `대시보드.html`에서 이관 (SCM/산업자재/물류장비/CES). PPS·글로벌은 신규 작성.
- 견적 단가 기본값은 참고용 — 화면에서 수정하면 기기(localStorage)에 저장됨.
- 업체·지식·체크 상태 모두 localStorage 저장 (서버 없음).

## 지게차 견적앱 (`forklift.html`)

현대자동차 차량 견적 페이지 UI를 오마주한 로지스올 MHE 지게차 임대 견적앱 (단일 파일).

- **01 기종 선택** → **02 내 장비 만들기** (동력·외장 → 마스트·타이어 → 옵션·안전 → 운영 조건)
- 좌측: 선택 사양(기종·색상·마스트 높이·타이어·배터리)에 따라 실시간 변하는 지게차 SVG 렌더링 + 월 임대료
- 우측: "Best 다른 고객들이 가장 많이 선택한 사양" 도넛 통계, 옵션 타일, 외장 색상 스와치
- 견적 로직은 KPP 물류장비 **「견적 필수 확인」 15항목** 기반 — 통로폭→기종 분기, 교대→충전기(단상/삼상) 자동 추천, 건설기계등록 제외요건 자동 판정
- **요약 보기**: 15항목 체크 상태(미확인 항목 표시) + 임대료 내역 + 견적요청 양식 복사
- 단가는 전부 참고용 더미 — 최종 임대료는 현장 실사 후 확정 문구 고정
